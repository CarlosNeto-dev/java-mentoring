*   **`app.py`**: O coração da nossa aplicação Flask. ❤️‍🔥
*   **`routes/`**: Define as rotas da aplicação, gerenciando como as URLs são mapeadas para o conteúdo. 🗺️
*   **`templates/`**: Armazena os arquivos HTML que compõem a interface do usuário da plataforma web. 🎨
*   **`static/`**: Contém arquivos estáticos como CSS, JavaScript e imagens para estilizar e adicionar interatividade à plataforma. 🖼️

## 📂 Folder Structure

Here is how the repository is organized:

### 📘 [theoretical_content](./theoretical_content)
Contains study materials and notes about Java concepts, now also accessible via the web platform. 💻

### 💻 [exercises](./exercises)
Contains practical coding exercises to test and improve your skills. 💡

### 🌐 Web Application Components
*   **`app.py`**: The core of our Flask application. ❤️‍🔥
*   **`routes/`**: Defines the application routes, managing how URLs are mapped to content. 🗺️
*   **`templates/`**: Stores the HTML files that make up the user interface of the web platform. 🎨
*   **`static/`**: Contains static files like CSS, JavaScript, and images to style and add interactivity to the platform. 🖼️
